# Reporting security issues

Report vulnerabilities privately through GitHub: on this repository's **Security** tab, choose **Report a vulnerability**. Please do not open a public issue.

This package branched from gopcua, but its security fixes are maintained separately: please do not report them to gopcua.
When a vulnerability also exists in gopcua's `ua`, `uasc`, `uacp` or `uapolicy`, the fix is recorded in [docs/CHANGES.md](docs/CHANGES.md) (Chinese only).
